# AGENTS.md — NeoVoiDrive

Three-band vocal texture effect plugin (VST3 + Standalone), JUCE 9.0.0, C++20, Windows x64. Per-band Jitter/Vibrato/Shimmer/Harmonic Exciter, Linkwitz-Riley crossover, dedicated STFT spectral-envelope formant shift (T68, no third-party runtime dependency).

## Project

- Stack: C++20, CMake ≥ 3.22, MSVC "Visual Studio 17 2022", Windows x64. JUCE 9.0.0: a local checkout at `stuff/JUCE` is used when present, otherwise CMake fetches tag 9.0.0 via FetchContent (both read-only). No external test framework — JUCE `UnitTest` only.
- Entry points: `source/PluginProcessor.cpp` (AudioProcessor + APVTS + engine orchestration), `source/PluginEditor.cpp` (UI), `tests/unit/UnitTestsMain.cpp` (console test runner), `tests/offline_render/Main.cpp` (CLI renderer).
- Published docs live under **`docs/`**: `docs/README.md` (build/test), `docs/USER_MANUAL.md`, `docs/SPEC.md` (params §4, latency §5), `docs/ARCHITECTURE.md`, `docs/AGENTS.md`, `docs/THIRD_PARTY_LICENSES.md`. Internal records (SIDEBAND_SPEC, DECISIONS, TESTPLAN, TASKS, audit reports, `test_report.md`, plan/analysis/risk/style guides) stay local and are not distributed. The repository root keeps only the user-facing `README.md`.

## Commands

```bash
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
ctest --test-dir build -C Release                    # unit_tests + offline_smoke
./build/tests/unit_tests_artefacts/Release/unit_tests.exe   # direct run (332 test cases / 60 suites)
./build/tests/offline_render_artefacts/Release/offline_render.exe --in=i.wav --out=o.wav [--param b1_jitter_depth=50]
```

- Optional LTO: `-DNVD_ENABLE_LTO=ON` (MSVC /GL+/LTCG, slower links).
- Perf gates (slow CI): env `NVD_P01_GATE_ON`/`NVD_P01_GATE_OFF` (default 15.0/6.0), `NVD_P04_GATE` (default 9.6).
- Golden-audio tests A05/A06 need `tests/assets/voice.wav` (macro `NVD_VOICE_WAV`); skipped automatically when missing.
- Artifacts: `build/NeoVoiDrive_artefacts/Release/{VST3,Standalone}`. Standalone is a local debugging build; the release ZIP packages the VST3 only.

## Architecture

- `source/PluginProcessor.*` — wires APVTS (68 params; T49 per-band Rough, T66 global Growl) → `dsp::MultibandEngine` in `processBlock`; dynamic latency via `dsp::LatencyManager`. Does no DSP itself; zero allocation after `prepareToPlay`.
- `source/params/` — `ParameterIDs.h` (IDs must match SPEC §4 verbatim), `ParameterLayout` (APVTS factory), `ParamSnapshot` (per-block atomic-load POD, the only param source on the audio thread).
- `source/dsp/` — `CrossoverBank` (LR2/4/6/8/10/12, 1–3 bands) → 3× `BandProcessor` (`PitchModUnit` → `ShimmerUnit` → `HarmonicExciter`/`SidebandEngine` crossfade → `BandFogUnit`), `MultibandEngine` (sum + polarity), `FormantEngine` (T68 dedicated STFT envelope warp: cepstral lifter + band-limited warp + OLA), `LatencyManager`, `ModDelayLine`, `ModLFO`, `RandomModSource` (S&H + continuous mode), `FogCore` (T51/T58 shared Hilbert constant-envelope phase fog for both Rough scopes).
- `source/ui/` — `NeoLookAndFeel`, `TopBarComponent`, `CrossoverDisplay`, `BandCardComponent`×3, `BottomBarComponent`; `SpectrumSource`/`MeterSource` are SPSC-FIFO bridges audio→UI.
- `source/util/` — `PresetBank` (embedded factory presets), `PresetIO` (T42 `.nvpreset` import/export + user library listing), `UserData` (app-data paths), `SpscFifo` (juce::AbstractFifo wrapper), `SmoothedValue`.
- `tests/` — `unit/` (JUCE UnitTest cases; new files auto-globbed via CONFIGURE_DEPENDS, re-run cmake to pick up), `offline_render/` (`RenderCore` shared with unit tests + `smoke_test.py`).
- `assets/fonts/` — `GoogleSansCode-VariableFont_MONO,wght.ttf`, committed and embedded via `juce_add_binary_data` (OFL 1.1, see `LICENSES/`).
- `stuff/` — optional local, **read-only**, not committed: JUCE checkout (`stuff/JUCE`); `stftPitchShift-2.0` (MIT) is historical only — since T68 the plugin does not include, compile, link or test against it, and the golden `voice.wav` fixture lives in `tests/assets/`; reference audio and the unused VictorMono font are local-only.

## Conventions

- **RT discipline**: `processBlock`/DSP `process()` are `noexcept`, no allocation, locks, exceptions, blocking, file IO, or logging. Audio thread reads params only via `ParamSnapshot` at block start; UI↔audio only via APVTS atomics or `SpscFifo` (drop-on-full, never block the audio thread).
- **DSP unit pattern**: header-only classes in `namespace dsp`, per-block `struct Params`, `prepare(sampleRate) noexcept`, `process(x) noexcept`, diagnostics getters for tests; smoothing via `juce::SmoothedValue` or `util::SmoothedValue`.
- Namespaces: `dsp::`, `ui::`, `params::`, `util::`.
- **Params are SPEC-driven**: any parameter change updates `docs/SPEC.md` §4 first; IDs stay verbatim.
- Sources are UTF-8 (MSVC `/utf-8`); the whole binary — including `source/dsp/FormantEngine.cpp` — stays at the SSE2 baseline (pre-Haswell compatible; no AVX2 translation units, since the formant engines are prepared/warmed even when Formant is off).
- Never modify the JUCE checkout (`stuff/JUCE` or `build/_deps/juce-src`). T68 removed the stftPitchShift include/compile dependency; the golden `voice.wav` fixture is stored in `tests/assets/`.
- Tests may include all of `source/` (DSP layer is independent of the plugin shell); no external test deps.
- Comments/commit references cite SPEC/DECISIONS/TESTPLAN sections (e.g. "T08, DECISIONS §1.3") — keep that habit.
